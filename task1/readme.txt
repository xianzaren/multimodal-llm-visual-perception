Task 1: Value identification

This directory contains utilities for generating scalar-field stimuli, mapping predicted coordinates back to source scalar values, and calculating value-identification error.

The benchmark uses five Perlin-noise spatial frequencies and nine colormaps. Large source matrices, image collections, fine-tuning data, prompts, and complete model outputs are hosted at https://osf.io/y4pgm/.

Several scripts are research snapshots and contain relative paths matching the original experiment workspace. Update input/output paths before running them.
